  6. 三份 .app 已同步更新：/Applications/千牛提醒.app、Documents/千牛提醒功能/千牛提醒.app、

【V3 更新（2026-09-05）—— 点击可靠性 + 事件驱动监控】

  源码：qianniu-swift/main.swift（旧版备份 main_v1_备份.swift / main_v2_备份.swift）

【这是一个自包含、可双击、可分享的 App】
  文件：千牛提醒.app（在 本 文件夹内）
  - 原生 Swift/AppKit 编写，通用二进制（Apple 芯片 + Intel 都能跑）
  - 自带图标；无 Dock 图标；只在菜单栏显示【黑白铃铛】图标
  - 不依赖 Python、不依赖任何安装包，拷贝整个 .app 文件夹即可用

【功能】
  - 监控千牛消息库写入（libaim/<账号>@cntaobao/database/im.sqlite-wal）
  - 千牛在后台时，右上角弹【千牛浅色卡片风】通知
  - 点击弹窗 → 切换到千牛；按住拖动可移动并记住位置；拖动中不消失，松手后 3 秒淡出
  - 千牛在前台时静默

【菜单栏图标（点一下）】
  - 开始提醒 / 暂停提醒        （暂停时图标变"静音铃铛"）
  - 立即测试弹窗
  - 播放提醒声音  → 可开关；勾选后弹窗额外播一声系统铃声
  - 提醒铃声：Glass → 可换（Glass/Ping/Purr/Pop/Submarine/Funk/Sosumi/Tink/Basso/Blow/Bottle/Frog/Hero/Morse）
  - 开启/关闭开机自启
  - 退出

【怎么用】
  - 启动：双击 千牛提醒.app
  - 暂停/恢复、开关声音、切铃声、自启：点菜单栏铃铛图标
  - 手动测试：菜单栏图标 → 立即测试弹窗

【装机 / 换电脑 / 分享】
  1. 把整个【千牛提醒.app】文件夹拷过去（U盘 / 微信 / AirDrop）
  2. 放到任意位置（建议 /Applications）
  3. 双击打开；首次如被拦：右键 → 打开 → 再点"打开"
  4. 自动读本机千牛消息库、自动注册开机自启（用当前位置，移动后重开一次即更新）

【源码 / 重新编译（可选）】
  Swift 源码：~/Documents/qianniu-swift/main.swift
  重新编译（生成通用二进制，最低 macOS 13.0）：
    cd ~/Documents/qianniu-swift
    xcrun swiftc -O -target arm64-apple-macosx13.0  -o q-a main.swift -framework Cocoa
    xcrun swiftc -O -target x86_64-apple-macosx13.0  -o q-i main.swift -framework Cocoa
    lipo -create -output QianniuNotify q-a q-i
    cp QianniuNotify ~/Documents/千牛提醒功能/千牛提醒.app/Contents/MacOS/ && chmod +x ...
  然后结束旧进程、open 该 App 重启。

日志（排查问题）：~/Library/Logs/qianniu_notify.log
